# SpotifyPremium

->Langkah Langkah
1. Donwload Spotify di [https://www.spotify.com/us/download/windows/] dengan menekan tombol "Download directly from Spotify"
2. Login akun Spotify
3. Buka web [https://spicetify.app/docs/getting-started]
4. Pilih opsi Docs pojok kanan atas
5. Pilih OS sesuai dengan laptop
6. Buka powershell(Win+R)
->Command<-
## Windows
iwr -useb https://raw.githubusercontent.com/spicetify/cli/main/install.ps1 | iex
## Linux
curl -fsSL https://raw.githubusercontent.com/spicetify/cli/main/install.sh | sh
## macOS
curl -fsSL https://raw.githubusercontent.com/spicetify/cli/main/install.sh | sh

7. Pilih "Y" enter, selanjutnya ketik "spicetify apply"
8. Masuk spotify pilih icon trolly(marketplace dari spicetify)
9. pilih extensions
10. Cari adblockify

Catatan :
Jika keranjang troli tidak muncul di spotify
Solusinya :
1. buka Run (Win + R)
2. ketik spotify:marketplace lalu enter
3. Marketplace di dalam aplikasi spotifynya seharusnya akan terbuka secara langsung
